# Momel Dev Portfolio

A modern, responsive personal portfolio website for **Momel Dev**, showcasing my journey, skills, projects, and interests as a developer.

## 🌐 Live Demo

[Visit the live portfolio](https://momel-dev.github.io/momel-dev-portfolio/)

## 📌 About the Project

This portfolio website was created to present my development skills and projects in a clean, modern, and professional way.

The goal is not only to showcase completed projects, but also to provide a clear overview of my technical interests, learning journey, and the type of work I am building toward.

## 🎨 Design

The design follows a minimal, modern visual style built around the Momel Dev identity.

The interface uses:

* Dark navy tones
* Glassmorphism elements
* Soft gradients
* Rounded components
* Responsive layouts
* Subtle visual effects

The design is intended to remain professional while still having a distinctive visual identity.

## 🚀 Running Locally

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/momel-dev/momel-dev-portfolio.git
```

2. Open the project folder.

3. Open `index.html` in a browser, or run it using a local development server.

## 📱 Responsive Design
